# Frigo Screen Spec

Target: 360 / 390 / 430 px.

1. Landing: logo + tagline + `Chụp thử tủ lạnh`.
2. Auth: Google / Email / Guest.
3. Onboarding: household size, cuisine, spice, restrictions.
4. Home: scan CTA → use soon → recipes → cuisine shortcuts.
5. Scan: idle/select/upload/process/error/ready.
6. Scan review: editable name, quantity, unit, confidence; fixed Confirm CTA.
7. Inventory: search, filters, freshness, CRUD.
8. Ingredient detail: illustration, quantity, freshness, source, recipes.
9. Recipes: cuisine/time/no-shopping/use-soon filters.
10. Recipe detail: hero → metadata → have/need/missing → steps → sticky Start.
11. Cooking mode: one step, progress, large text.
12. Complete: show inventory before/after; require confirmation.
13. Shopping list: checkbox list.
14. Notifications: freshness/recommendations/scan status.
15. Profile/Settings: simple list UI.
16. Plus: real HTML paywall using brand tokens; illustration is support only.

Bottom nav: Home / Tủ lạnh / Scan / Món ăn / Tôi.
Scan is central and visually dominant.
