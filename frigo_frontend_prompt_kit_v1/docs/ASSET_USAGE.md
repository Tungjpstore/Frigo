# Asset Usage

## Brand
- `logo-primary.png`: landing/header lớn
- `wordmark.png`: compact top bar
- `mark.png`: splash/auth/loading
- `/app-icons/*`: manifest/favicon

## Illustrations
- `scan-fridge`: landing/home scan CTA
- `empty-fridge`: inventory empty
- `no-recipes`: recommendation empty
- `shopping-ready`: shopping list
- `delicious-meal`: cook complete
- `use-soon`: expiry education
- `world-cuisines`: onboarding/explore
- `frigo-plus`: paywall support art

## Recipe images
Dùng làm seed/demo production:
Vietnam: thit-kho-trung, dau-phu-sot-ca-chua, rau-muong-xao-toi, canh-chua-ca, com-chien-trung, ga-kho-gung.
Global: kimchi-fried-rice, oyakodon, pad-krapow, tomato-egg-stir-fry, pasta-pomodoro, mapo-tofu.

## Ingredient PNG
Dùng ở scan review, inventory row, ingredient chip/detail.
48–96px, `object-fit: contain`.

## Reference
`public/frigo/reference/*` chỉ để agent quan sát phong cách; không ship vào viewport người dùng.
